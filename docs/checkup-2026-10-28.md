## Findings

1. The package meter hardcoded pacman, AUR and Flatpak. It now has a native
   backend probe and labels the active source.
2. Search ranked page metadata without its catalog id, so Enter could not open a
   result. Results now keep `id` and activation has a static contract.
3. README described the upstream snapshot. It now documents the current fork,
   default keybinds, Search, RPM support, quality gates, credits and decisions.
4. CI assumed an Arch runner and bash syntax under `sh`; the static gate now
   selects the script interpreter from its shebang and the package selftest does
   not require pacman.

## Residual limits

- RPM behavior has fake-manager tests, not a real Fedora or openSUSE VM run.
- Every panel opens in the smoke test, but every individual control was not
  clicked by automation.
- Search row-level focus, updater adversarial fuzzing and a real updater apply
  remain open.
- Two physical outputs, hotplug and mixed DPI remain untested.
- The QML monoliths are still above the long-term file budget.
