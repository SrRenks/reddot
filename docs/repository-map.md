# Repository map

| Path | Role |
|---|---|
| `configs/hypr/` | Hyprland Lua modules, scripts and helpers |
| `configs/quickshell/pill/` | Pill QML, surface catalog, search and status |
| `configs/quickshell/lock/` | Lock QML and PAM authentication |
| `configs/fish/`, `configs/ghostty/` | Shell and terminal configuration |
| `configs/sddm/` | Torii SDDM theme |
| `installer/packages.json` | Package manifest used by the Rust planner |
| `installer/starter-wallpapers/` | Seed wallpapers for post-install |
| `tools/*.rs` | Rust installer, updater, palette, deploy and checks |
| `tools/check.sh` | Local checkout gate |
| `tools/check-static.sh` | Headless CI gate |
| `docs/` | User and maintainer documentation |
| `assets/` | New screenshots and README recordings |
| `README.md`, `CHANGELOG.md` | Entry point and history |
