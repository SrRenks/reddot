# Roadmap

## Validation

- Updater with a real file conflict and rollback.
- Physical cable hotplug, mixed DPI and a two-output PAM unlock.
- Reinstall idempotence on Fedora, Tumbleweed and Arch (Debian done).
- Individual controls across all 41 surfaces; Search row focus.
- Optional installer paths: SDDM, GRUB, Brave and fish.

## Maintenance

- Keep the supported matrix at Arch, Debian 13+, Fedora 44+ and Tumbleweed.
- Do not re-add Leap/Gentoo without a source-build design and VM coverage.
- Keep QML surfaces unloaded when cold; measure before adding a plugin layer.
